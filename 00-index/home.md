# Home

Root map of the vault. Start here; branch into a domain MOC. Every domain MOC is reachable from this note, and every note is reachable from a MOC (see the zero-orphan rule in [[AGENTS]]).

## Contract
- [[AGENTS]] — the write contract (read first, every session)
- [[frontmatter-schema]] — YAML on every note
- [[tag-registry]] — the closed tag vocabulary
- [[moc-holding]] — orphan catcher for notes without a home yet

## Domains
Replace these with your own. Each links to a domain MOC that curates the notes in that area.

- **Research** — the atomic knowledge core (`40-research/`)
- **Infra** — hosts, services, stacks (`30-infra/`)
- **Projects** — product/build notes (`10-projects/`)

## Cadence
- Daily logs live in `60-daily/`.
- The full-vault health sweep (see [[AGENTS]]) runs on a cadence and logs evidence to `_meta/log.md`.
