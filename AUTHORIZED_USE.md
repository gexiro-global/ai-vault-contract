# Authorized Use

This repository is documentation and a starter file structure. It runs nothing on its own and makes
no network connections. `tools/lint_vault.py` reads Markdown files under a directory you point it at
and prints results; it writes nothing.

Use it for a vault you own. When you adapt it, remember the contract's own rule: keep secrets and
your own infrastructure's public addresses out of any note you might later share or publish.
